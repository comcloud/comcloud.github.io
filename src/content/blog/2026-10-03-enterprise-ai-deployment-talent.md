我的判断是，企业 AI 的稀缺资源正在从“能不能拿到一个强模型”，转向“有没有人能把模型穿过安全、数据、流程和组织阻力，真正放进生产系统”。Anthropic 10 月 2 日宣布投入 1 亿美元，计划到 2027 年底训练 1 万名 Frontier Deployed Engineers，我更愿意把它看成商业化阶段变化的信号，而不是一次培训营销。

一个常见说法是：模型再强一代，企业自然就会大规模采用。这个说法的问题在于，它把企业当成一个巨大的 API 客户，却忽略了真实公司里最麻烦的部分从来不在模型接口。

Anthropic 公布的 Claude Frontier Academy 很具体。首批参与者来自 Accenture、Bain、Capgemini、Deloitte、McKinsey、Morgan Stanley、Novo Nordisk 等机构。候选工程师先做数天线下模拟部署和考核，通过后再进入 12 周 residency，回到自己的组织里负责一个真实 Claude 项目，最后再接受一次实践考核。Anthropic 说，目标是在 2027 年底前训练 1 万名 FDE。

这套设计最有意思的地方，是它并不把 FDE 定义成“更会写 Prompt 的人”。

## 企业 AI 的工作，正在从模型调用变成系统改造

一个 Agent 真正进入企业以后，至少会碰到身份认证、权限、内部数据库、旧系统接口、审计、安全评审、人工审批、失败恢复和责任归属。模型回答得更聪明，只能解决其中一部分。

例如，一个财务 Agent 能看懂发票并不难，难的是它能否访问正确的 ERP；能不能区分只读和写入权限；金额超过阈值时是否必须交给人；某个供应商资料冲突时应该停在哪里；一次错误付款发生后能否追溯当时用了哪些数据。

这些事情都不是换一个更大的模型就自动消失。

所以 FDE 这类角色的价值，可能恰恰在“跨边界”：既懂软件工程，也能理解业务流程，还得知道哪些动作不能交给模型自己决定。Anthropic 自己也把安全评审和交接放进了训练流程，这说明厂商知道，真正的交付不是做出一个漂亮 Demo，而是让系统能长期运行。

## 咨询公司可能重新变成 AI 厂商最重要的分发渠道

首批名单里有大量咨询和专业服务公司，这件事比“培训 1 万人”本身更值得研究。

过去 SaaS 厂商的理想增长方式，是产品足够标准化，然后客户自己买、自己部署。Agent 时代未必完全这样。越往核心业务走，企业越需要有人进入现场，把现有流程拆开、重新定义权限、连接内部系统，再把 Agent 放进去。

这会让 Accenture、Deloitte、McKinsey 这类机构重新成为很重要的技术分发层。模型厂商培训的不是自己公司的员工，而是在训练一批可以进入成千上万家客户内部的人。

如果这条路线成立，模型公司的竞争就不只是 API 性能和价格，还会包括谁拥有更大的实施网络、谁定义了企业部署的方法、谁的安全规范被咨询公司带进更多客户。

这种渠道一旦形成，也会带来新的锁定效应。企业以后更换模型，成本可能不只在代码迁移，而在一整套围绕某个厂商建立的权限体系、评测方法、员工技能和运营流程。

## FDE 可能把“软件产品”和“专业服务”的边界重新打乱

传统软件公司一直希望减少服务比例，因为服务难复制、毛利也通常不如标准软件漂亮。但 Agent 产品有一个矛盾：越想进入高价值业务，越需要理解客户自己的流程；越理解客户流程，就越难完全标准化。

所以我怀疑，企业 AI 最赚钱的一部分可能出现一种新的组合：底层模型高度标准化，上层部署却高度贴近客户。

FDE 的作用就是把两者接起来。

这也意味着，未来衡量一家企业 AI 公司，不能只看模型调用量。更关键的问题可能是：一个部署工程师同时能支持多少生产系统；项目从立项到上线要多久；上线半年后还有多少人工维护；一个客户的经验能不能抽象成下一个客户可复用的模板。

如果这些指标无法改善，那么所谓 FDE 只会变成更昂贵的驻场外包。

## 对人才市场的影响，可能比“会不会写代码”更复杂

Business Insider 报道称，在截至今年 5 月的一年里，头部咨询公司的 FDE 相关职位增加了 1,404 个。这个数字来自第三方岗位数据，口径需要继续核实，但方向和 Anthropic 的投入是一致的：市场开始需要一类同时懂技术、业务和部署的人。

这对工程师的要求其实更高了。

纯粹会调用模型 API 很快会变成基础技能。更稀缺的能力可能是：能读懂一个组织真实的系统关系；能把业务规则变成可执行约束；能设计评测和回归；能判断哪些步骤必须保留人工；能在模型、数据库、权限系统和现有软件之间做工程取舍。

换句话说，Agent 越强，人反而越需要理解“系统”。

## 风险在哪

第一，Anthropic 的 1 万人只是目标，目前没有公开最终通过率，也没有长期 ROI 数据。培训做得好，不等于这些项目一定能给客户创造足够价值。

第二，这套认证由模型厂商自己设计，很容易带上厂商绑定。一个“Claude FDE”学到的究竟是通用的 Agent 工程能力，还是更熟练地把企业锁进 Claude 体系，需要看课程和真实项目。

第三，今天很多部署工作也可能被 Agent 自己自动化。连接 API、迁移数据、写测试、生成权限配置，这些任务正在快速被 Coding Agent 接管。如果模型进步很快，FDE 的人数需求可能没有厂商预测得那么大，真正稀缺的会进一步上移到架构、治理和业务判断。

第四，咨询公司自己的商业激励也不能忽略。复杂项目越多，专业服务收入越高。把所有企业 AI 难题都归结为“缺部署人才”，可能会低估产品标准化最终能解决多少问题。

## 我可能错在哪

我目前倾向于认为，未来两三年企业 AI 的主要约束会是部署能力，而不是模型能力。但如果 Agent 很快能够自己完成系统集成、测试、权限分析和上线运维，那么今天需要大量 FDE 的阶段可能只是一个过渡。

另一种可能是，企业根本不愿意把关键系统交给外部驻场团队，最后还是由内部 IT 和业务团队主导，FDE 只负责早期导入。

这两种情况都会削弱“部署人才成为核心稀缺资源”的判断。

下一步我最想查的，是第一批 FDE 项目的真实运营数据：从立项到生产用了多少周；上线六个月后需要多少人工维护；一个工程师同时支持几个系统；客户是否真的减少了外部顾问依赖；更换底层模型时迁移成本有多高。只有这些指标出来以后，才能判断 Anthropic 是在培养一个新的工程职业，还是在为企业 AI 的过渡期补人。
