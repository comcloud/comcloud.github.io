我越来越觉得，AI 云接下来的竞争不会继续停留在“谁手里的 GPU 更多”。真正决定利润的单位正在从 GPU 小时变成 token：同一块卡一天到底能产出多少可收费的有效推理，才是新的成本曲线。

10 月 1 日，Nebius 宣布收购成立不到一年的 Inferize，交易价格未披露。Inferize 做的事情很窄：缩短大模型启动和扩容时的 cold start，让新实例更快进入服务状态。Nebius 自己把这部分闲置称为“idle GPU tax”——需求突然上升、模型权重更新、强化学习过程中切换版本时，如果新实例起得慢，平台就得提前养一批空闲 GPU 来保证 SLA。

单看这个功能，很容易把它理解成一次普通的工程团队收购。我认为更重要的是 Nebius 今年已经连续把三层推理能力往自己体内收：5 月收购 Eigen AI，补模型、kernel 和系统层优化；随后引入 Clarifai 核心团队并获得推理与计算编排技术；现在再买 Inferize，补弹性扩容和冷启动。它在做的已经不是“租 GPU”，而是在造一个完整的 token 工厂。

第一，AI 云的成本优势开始从采购价转向利用率。

早期 AI 云很好理解：拿到稀缺 GPU，建好数据中心，然后按小时出租。只要芯片供给紧，硬件本身就是护城河。但推理规模上来以后，客户并不关心你买一张卡多少钱，他们关心的是每百万 token 的价格、响应延迟、峰值时能不能扩起来。

Nebius 的 Token Factory 已经直接按 token 定价，并把自动扩缩、专用 endpoint、延迟和利用率作为产品卖点。公司官网声称，通过优化 serving pipeline，某些场景可以做到更好的成本性能比。这个数字属于厂商口径，不能当行业平均，但商业方向很清楚：只要一张 GPU 的有效产出提高 20%，在大规模推理里，价值可能比采购时便宜 5% 更大。

这意味着纯粹依靠“我有卡”的云厂商会越来越难。算力租赁最终很像服务器托管，真正能留下利润的，是调度、模型优化、缓存、并行、量化、弹性和长期负载数据。

第二，推理优化创业公司的买家正在发生变化。

过去做 kernel、编译器、serving、模型压缩的团队，最自然的商业路径是卖软件给很多客户。现在一个新的退出方向越来越明显：直接被云厂商或芯片生态吸收。

原因不难理解。推理优化和底层基础设施耦合太深。一个独立团队即使把 cold start 做得很好，如果无法同时控制 GPU 调度、模型加载、网络、存储和计费，很多性能收益最终会在别的层被吃掉。反过来，Nebius 把这些团队收进平台，可以直接把技术收益变成自己的毛利。

这对创业者既是机会，也是提醒。机会是，大厂愿意为少数能实质降低 token 成本的系统团队付钱；提醒是，单点工具如果不能形成独立客户价值，很容易最后成为基础设施公司的一个 feature，而不是一家长期独立的软件公司。

第三，客户预算也会发生变化：从“买计算资源”变成“买结果吞吐”。

如果推理平台能把 GPU 利用率、弹性、延迟这些复杂问题藏起来，企业采购时就更容易比较“处理一百万次请求花多少钱”，而不是理解某种 GPU 集群应该怎么配。这会把 AI 基础设施逐渐拉向云数据库、CDN 的商业模式：客户购买的是稳定服务指标，底层机器怎么组织由供应商承担。

对云厂商来说，这是一把双刃剑。好处是可以通过工程能力做出毛利差异；坏处是客户也更容易直接比较每 token 价格。一旦接口标准化，切换成本低，价格透明度会非常高。最后的竞争可能不是“谁最贵但最好”，而是谁能持续把硬件、模型和软件三层成本压下来。

第四，真正的护城河可能变成真实流量，而不是某个算法。

Inferize 成立于 2026 年 1 月，三个月就做出原型。这说明单点技术创新可以很快出现。真正难复制的，反而可能是平台长期服务真实客户后积累的负载形态：什么时候流量暴涨、哪类模型最容易冷启动、不同客户愿意用多大延迟换价格、哪些权重最常切换。

有了这些数据，平台才能决定优化什么。也就是说，推理基础设施最后可能和广告、搜索一样，规模本身反过来提升系统效率。

## 我可能错在哪

第一个风险是，Nebius 自己公布的性能和成本数据主要来自厂商测试，真实客户在不同模型、不同区域和不同流量模式下，收益可能差很多。

第二，开源推理框架进步非常快。vLLM、SGLang、TensorRT-LLM 以及芯片厂商自己的软件栈，都可能把今天有价值的优化迅速做成公共能力。如果冷启动、调度、量化最终高度标准化，收购来的技术并不一定形成长期差异。

第三，Nebius 连续收购也可能说明另一件事：它需要快速补课。把多个团队和系统整合到统一平台并不容易，技术栈越复杂，组织整合和维护成本也越高。

所以我不会简单把这次收购理解成“AI 推理又热了”。我更关心的是，AI 云的商业单位是不是已经正式从 GPU/hour 迁移到 token economics。

下一步我会查三组数据：不同 AI 云厂商每张 GPU 的实际 token 产出和利用率；同一个模型在 serverless、专用 endpoint 和自建集群下的真实单位成本；以及过去一年被收购的推理优化公司，技术最终有没有真正进入生产主路径。只要这三组数据逐渐透明，我们就能判断 AI 云最后会是一门硬件生意，还是一门系统工程生意。
