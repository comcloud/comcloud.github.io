我觉得，Agentic Commerce 真正会改写的不是“购物体验”，而是商家的渠道资产。过去商家花钱优化搜索排名、页面、广告和转化漏斗；如果消费者以后先把需求交给 AI，再由 Agent 比价、选品、下单，商家最重要的问题会变成：机器能不能正确读懂我的商品、价格、库存、配送和交易规则。

9月22日，Reuters 报道，多家全球银行开始公开警告 AI shopping agent 的诈骗、欺诈和隐私风险。报道同时给了一个很值得注意的业务数据：英国零售商 John Lewis 表示，来自 AI agent 的搜索流量占比在一年里从0.3%升到2.5%。绝对比例仍然很小，但它证明“消费者先问 Agent，再进商家”已经从演示进入真实流量。

支付网络其实已经提前行动。Mastercard 9月9日发布 Agent Connect 和扩展版 Agent Suite for Merchants，核心不是自己做一个购物机器人，而是帮助商家把商品详情、价格、库存、履约信息以 Agent 可以理解和调用的方式开放出去，并用一个接入点连接不同 AI agent、平台和支付方。Visa 同期公布的调查则显示，美国受访者里只有23%愿意信任生成式 AI 代为完成支付，但61%表示愿意信任 Visa 处理 Agent 交易。

把这几件事放在一起，我看到的是一个渠道重构，而不只是一个新功能。

第一，电商的“首页”可能从网页变成结构化商品数据。

人类逛网站时会看图片、文案、品牌故事、推荐位。Agent 不需要这些视觉路径，它更关心 SKU 是什么、规格是否符合、库存还有没有、今天送不送得到、最终税费多少、退货规则怎样。

这会让很多过去属于前端运营的能力，转成后台数据基础设施。商品信息是否完整、价格是否实时、不同渠道的数据是否一致，会直接影响 Agent 是否愿意把商品放进候选集合。

所以未来所谓“Agent SEO”如果只是给商品描述里多塞关键词，我觉得很可能走偏。真正的竞争是把 catalog、inventory、pricing、fulfillment 做成机器可验证的数据接口。

第二，商家会失去一部分页面控制权，却可能重新争夺交易规则控制权。

传统电商里，商家至少能控制自己的站点页面；进入平台以后，控制权交给搜索排序和推荐算法。Agent 又增加一层新的中介：消费者甚至可能不再看到商品页，只看到 Agent 给出的三种选择。

这对品牌很危险。一个依赖视觉、内容和情绪价值的品牌，如果被 Agent 简化成“价格、评分、配送、参数”几列数据，过去花钱积累的页面体验可能会被压缩。

Mastercard 的方案为什么反复强调 merchant control，我觉得原因就在这里。它希望商家仍然能决定哪些 Agent 可以访问、怎样展示产品、最终价格和履约规则是什么，以及如何维持客户关系。

未来商家真正会争的，不只是“有没有 Agent 流量”，而是 Agent 经过谁的接口、拿到哪些数据、交易完成以后客户身份归谁。

第三，支付公司可能成为 Agent 商业世界里的信任层。

今天大家容易觉得，购物 Agent 的主导权一定会落在模型平台手里。可一旦 Agent 从推荐走到付款，事情就不一样了。

付款需要身份验证、授权、tokenization、争议处理、退款和欺诈责任。模型公司可以决定“买什么”，但并不天然拥有几十年形成的支付风控和商户网络。

Visa 的调查很有意思：消费者对 GenAI 直接处理付款的信任只有23%，但对 Visa 处理 Agent 交易的信任达到61%。这是 Visa 自己委托的调查，不能当成市场定论，但它说明消费者可能把“智能决策”和“资金托管”分给不同主体。

如果这种分层成立，支付网络不会因为 Agent 出现而被绕开，反而可能从后台通道升级成新的身份和授权基础设施。

第四，广告和获客的利润池可能重新分配。

今天搜索引擎、电商平台和社交媒体能赚大量广告费，是因为它们控制用户发现商品的入口。如果 Agent 直接替消费者搜索、比较和筛选，传统点击广告的价值会下降。

但这并不意味着商家获客成本一定下降。新的 Agent 平台完全可能收取推荐费、成交佣金，或者把“优先进入候选集合”变成新的广告产品。旧中介减少一个，新中介可能马上出现。

对创业公司来说，我反而更看好不依赖流量垄断的中间层：商品数据清洗、Agent-ready catalog、跨平台库存同步、价格规则、交易授权、争议证据和 merchant analytics。这些能力不需要成为消费者入口，也能随着 Agent 交易量增长。

## 风险在哪

现在最大的风险，是把2.5%的流量增长外推得太快。

John Lewis 的数据证明 Agent 导流在增长，却远不能证明主流消费者已经把购物决策交出去。Visa 的调查同样显示，支付环节的信任仍然很低。大量用户可能愿意让 AI 找商品，却不愿意让它直接付款。

第二，责任边界还很模糊。Agent 买错规格、商家库存数据过期、模型被诈骗网站诱导、用户事后否认授权，到底由平台、支付方还是商家承担损失？银行这次集体发声，本质上说明交易速度正在跑到规则前面。

第三，Agent 可能让渠道更加集中，而不是更加开放。如果最终只有两三家超级 Agent 掌握大多数消费者意图，商家对它们的依赖甚至可能比今天对搜索平台更强。所谓“机器帮消费者比价”，也可能演化成新的平台权力。

我可能错在高估商家愿意重新建设数据和接口。大型平台可能直接从现有网页、feed 和支付接口里把信息抽走，商家只需要继续维护现在的系统，那么“Agent commerce infrastructure”就不会形成很大的独立软件市场。

下一步我最想查五个数：Agent 导流的实际转化率；这种流量的获客成本和传统搜索相比差多少；Agent 发起交易的拒付和欺诈率；成交后商家能否保留客户身份；以及平台最终抽多少佣金。等这些数字出现，我们才知道购物 Agent 是帮商家拿回渠道权，还是只是换了一个新的入口收租者。
