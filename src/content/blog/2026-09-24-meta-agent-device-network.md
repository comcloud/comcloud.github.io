我觉得，Meta 这次最值得商业世界看的，不是哪一副眼镜参数更强，也不是突然多出一个叫 Charm 的小设备，而是它似乎没有准备押注“下一台超级终端”。它正在做另一件事：把同一个个人 Agent——Muse——铺进越来越多的终端，让硬件本身变成分发 Agent 的渠道。

9 月 23 日的 Meta Connect 上，扎克伯格公布了 Meta Charm。Reuters 报道，这是一台大约 AirPods 盒大小的独立设备，带约 2 英寸触摸屏和 5G 连接，计划在今年 12 月假日季出货，价格尚未公布。Charm 的核心并不是自己形成一套新应用生态，而是让 Muse 随身存在，能够直接使用实时语音和虚拟形象能力。

同一天，Meta 还把 AI 眼镜产品线继续铺开。官方宣布，到今年年底，Ray-Ban、Oakley 和 Meta Glasses 将合计提供超过 100 种眼镜选项；新的入门款 Meta Adventurer 起价 249 美元，Ray-Ban Meta Audio 走的是无摄像头、轻量、全天佩戴路线。更重要的是，Muse 会进入这些眼镜。Meta 9 月 8 日发布 Muse 时，已经把它放在独立 App、网页和 WhatsApp 里，并明确说大多数基础能力免费，高强度使用再通过订阅收费。

把这些产品放在一起，我看到的不是一次硬件发布会，而是一种和手机时代不太一样的分发策略。

第一，Meta 可能不需要任何一台设备单独“取代手机”。

AI 硬件市场过去两年最容易讲的故事，是谁能造出 post-smartphone device：眼镜、胸针、吊坠、随身录音器，大家都在找下一台每天使用十小时的超级终端。但这种目标太难。手机已经把屏幕、支付、相机、通信和应用生态做得极其成熟，新设备只要有一个明显短板，用户就会回到手机。

Meta 的做法更像是把一个 Agent 分散到不同场景里。走路、开车、运动时，眼镜比手机自然；坐下来处理复杂信息时，手机和电脑更自然；Charm 则试图占一个“随手拿起就能说”的位置。每个终端都不必完成全部任务，只要降低某一类场景里调用 Muse 的摩擦就够了。

这会把硬件竞争从“哪台机器功能最多”，改成“谁能让同一个 Agent 出现在最多真实生活场景”。

第二，硬件的经济价值可能越来越接近获客和留存，而不只是硬件毛利。

Muse 本身已经有免费层和订阅层，还能替用户购物、订旅行、填表、发邮件，支付环节接入 Stripe Link。也就是说，Meta 可以从至少几种路径理解硬件价值：卖设备本身、提高 Muse 使用频率、提高付费订阅转化、增加交易和服务连接机会，最后还有可能形成新的开发者生态。

这和一家纯硬件创业公司差别很大。后者每卖一台机器都必须尽量靠硬件毛利活下去；Meta 可以容忍某些设备利润不高，只要它们能够把用户带进 Muse，并提高整个账户体系的使用时长和粘性。

Charm 目前连价格都没有公布，所以现在还不能判断它会不会被补贴。但商业上真正应该观察的，不只是单台设备卖多少钱，而是“拥有设备的人，Muse 的日活和付费率到底提高多少”。如果这个数字明显，硬件就开始像一种渠道投资。

第三，Meta 眼镜真正难复制的部分，可能不是 AI，而是消费品分销。

官方这次反复强调与 EssilorLuxottica 的合作，到年底超过 100 种款式，而且继续进入新国家。眼镜和手机不一样，它直接戴在脸上。重量、镜框、度数、风格、试戴、售后都会影响购买。一个 AI 创业公司即使模型很好，也很难快速补齐这些零售和供应链能力。

这说明 AI 穿戴设备最后未必只是一场模型能力竞争。谁能进入眼镜店、谁能提供处方镜片、谁能让用户愿意一天戴八小时，可能和语音延迟一样重要。

对创业公司来说，这是一个很现实的提醒：如果产品价值建立在“我也做一台带模型的小硬件”上，渠道和售后可能比模型本身更快把成本拉高。反而更有空间的，可能是给现有硬件品牌提供 Agent 能力、场景软件、行业服务和配套应用，而不是从零复制整套消费电子体系。

第四，真正的护城河可能逐渐从设备迁移到跨设备的身份、记忆和权限。

用户今天在 WhatsApp 里告诉 Muse 自己下个月要旅行，明天戴眼镜时它如果还记得行程，Charm 上继续对话时又能接着做，这种体验的价值来自“同一个 Agent 一直在”，不是某一块屏幕。

这会产生一种新的切换成本。换一副眼镜并不难，真正难的是把长期记忆、连接的邮箱、支付方式、审批习惯和已经进行到一半的任务全部迁走。硬件越多，反而越可能让 Agent 账户成为中心，设备变成外围。

从这个角度看，Meta 的优势也很特别：它已经拥有 WhatsApp、Instagram、Facebook 和庞大的社交关系网络。如果 Muse 能在严格权限和隐私边界内使用其中一部分上下文，硬件就不是孤立的新产品，而是把已有账户体系延伸到现实世界的接口。

## 风险在哪

我可能高估了用户愿意为“随时能叫到 Agent”再买一台设备。手机已经足够近，很多人没有理由额外携带 Charm；眼镜也存在隐私、审美、续航和社交接受度问题。设备越多，库存、维修、退货和软件适配成本也越高。

第二，跨设备记忆同时也是隐私风险。一个 Agent 越长期、越懂用户，一次权限配置错误或数据泄露的影响就越大。Meta 可以把 Muse 铺到更多终端，但用户是否愿意把邮件、支付、日程和现实环境长期交给同一个账户体系，仍然没有被证明。

第三，硬件分发不等于 Agent 留存。设备可以卖得不错，用户也可能只把眼镜当耳机和相机，把 Muse 当偶尔使用的功能。超过 100 种款式证明 Meta 在扩大产品覆盖，却不能证明 Agent 已经成为购买理由。

什么证据会推翻我的判断？如果一年后 Charm 销量很低，AI 眼镜用户使用 Muse 的频率和普通 App 用户没有明显差异，订阅转化也没有因为硬件提高，那这些设备仍然主要是一门消费电子生意，而不是 Agent 的分发网络。

下一步我最想查五个数：佩戴 Meta 眼镜的用户每天调用 Muse 几次；硬件用户的 Muse 订阅转化率比纯 App 用户高多少；跨设备完成一个长任务的比例有多高；Charm 的退货率和持续使用率怎样；以及 Meta 每获得一个高频 Muse 用户，在硬件补贴、渠道和售后上到底花多少钱。

如果这些数字成立，AI 硬件市场可能不会出现一台“下一代手机”。更可能发生的是，一个强 Agent 先占住账户和长期关系，再通过很多不同形态的设备进入用户一天中的不同场景。到那时，硬件本身最重要的商业价值，可能只是让那个 Agent 离你再近一点。
